# 系统逻辑简化版

## 🎯 一眼看懂的流程

```
┌──────────────┐
│   👤 用户    │
└──────┬───────┘
       │
       │ 上传Excel文件
       │ (唯一输入)
       ↓
┌──────────────────────────────────────┐
│      🤖 系统（assessment-skill）      │
├──────────────────────────────────────┤
│                                       │
│  【系统内置文件】                     │
│  ✅ main.py                          │
│  ✅ pdf_generator_v2.py              │
│  ✅ 综合段位语料库.txt                │
│  ✅ 能力维度语料库.txt                │
│  ✅ 行动计划语料库.txt                │
│                                       │
│  【自动处理】                         │
│  1. 读取Excel数据                    │
│  2. 加载语料库（自动）                │
│  3. 计算段位+等级                    │
│  4. 匹配语料库内容                   │
│  5. 生成PDF                          │
│                                       │
└──────────────┬───────────────────────┘
               │
               │ 输出PDF
               ↓
┌──────────────┐
│ 📄 PDF报告   │
│ (多份)       │
└──────────────┘
```

## 📦 系统结构

```
assessment-skill/
│
├── 📄 main.py                        ← 主程序（处理Excel）
├── 📄 pdf_generator_v2.py            ← PDF生成器
├── 📄 skill.json                     ← 配置文件
│
├── 📚 综合段位语料库.txt              ← 系统内置，自动加载
├── 📚 能力维度语料库.txt              ← 系统内置，自动加载
└── 📚 个性化发展行动计划语料库].txt   ← 系统内置，自动加载
```

---

## 🔄 核心处理流程

```
Excel数据进入系统
       ↓
┌─────────────────────────────────┐
│ 步骤1：提取数据                  │
├─────────────────────────────────┤
│ • 用户信息：序号、昵称、时间     │
│ • 9项能力得分                    │
│ • 总分 = 9项得分之和             │
└─────────────────────────────────┘
       ↓
┌─────────────────────────────────┐
│ 步骤2：计算段位                  │
├─────────────────────────────────┤
│ 总分46.26分 → 查表 → 五段        │
│                                   │
│ 根据分数区间自动匹配段位          │
└─────────────────────────────────┘
       ↓
┌─────────────────────────────────┐
│ 步骤3：判定等级                  │
├─────────────────────────────────┤
│ 执行力 4.89分 → D级              │
│ 协调力 6.00分 → C级              │
│ 优化力 4.44分 → D级              │
│ ... (9个能力全部判定)            │
└─────────────────────────────────┘
       ↓
┌─────────────────────────────────┐
│ 步骤4：匹配语料库                │
├─────────────────────────────────┤
│ ① 段位描述：                     │
│   五段 → corpus['rank']['五段']  │
│                                   │
│ ② 能力解读：                     │
│   执行力D级 →                    │
│   corpus['ability']['执行力']['D']│
│                                   │
│ ③ 行动建议：                     │
│   五段 + 执行力 →                │
│   corpus['action']['执行力']['4-6段']│
└─────────────────────────────────┘
       ↓
┌─────────────────────────────────┐
│ 步骤5：生成PDF                  │
├─────────────────────────────────┤
│ • 封面（用户信息+段位）          │
│ • 第一部分（段位释义+雷达图）    │
│ • 第二部分（9能力深度解读）      │
│ • 第三部分（个性化行动计划）      │
└─────────────────────────────────┘
       ↓
   PDF报告完成
```

## 💡 关键点

### 用户只需要：
```
✅ 准备Excel文件（测评数据）
❌ 不需要关心txt文件（系统内置）
❌ 不需要关心如何计算段位
❌ 不需要关心如何匹配内容
```

### 系统自动完成：
```
1. 启动时自动加载3个txt语料库
2. 读取Excel数据
3. 计算段位和等级
4. 从语料库匹配对应内容
5. 生成专业PDF报告
```

### 内容来源：
```
100% 来自txt语料库文件
- 段位描述 ← 综合段位语料库.txt
- 能力解读 ← 能力维度语料库.txt
- 行动建议 ← 行动计划语料库.txt
```

## 🚀 使用示例

```bash
# 用户只需要运行：
python main.py "测评数据.xlsx" -o "输出目录"

# 系统自动：
# 1. 加载语料库
# 2. 处理Excel所有行
# 3. 为每行生成PDF
# 4. 保存到输出目录
```
