# 九段总助胜任力专业测评报告生成系统

## 📋 功能介绍

这是一个自动化的职场胜任力测评报告生成系统，通过Excel问卷数据自动生成详细的个人能力评估报告。

### 核心功能

- ✅ 读取Excel测评数据
- ✅ 自动计算9大能力维度得分
- ✅ 判断能力等级（A-E级）
- ✅ 评定综合段位（一段至九段）
- ✅ 生成个性化能力分析报告
- ✅ 提供针对性发展建议

---

## 🎯 测评体系

### 九大能力维度

**核心基石（8分制）**
- 执行力：日常事务处理能力
- 协调力：跨部门沟通协作能力
- 优化力：流程改进和效率提升能力

**价值引擎（10分制）**
- 统筹力：多任务和资源整合能力
- 预见力：风险预警和趋势判断能力
- 业务力：业务理解和支持能力

**领导潜能（12分制）**
- 财务力：财务分析和决策支持能力
- 领导力：团队管理和人才培养能力
- 决策力：战略判断和独立决策能力

### 九段位体系

| 段位 | 分数范围 | 角色定位 |
|------|----------|----------|
| 一段 | 0-15.09 | 被动执行者 |
| 二段 | 15.1-30.09 | 可靠执行者 |
| 三段 | 30.1-40.09 | 主动思考者 |
| 四段 | 40.1-45.09 | 协调枢纽 |
| 五段 | 45.1-55.09 | 系统优化者 |
| 六段 | 55.1-70.09 | 策略运作专家 |
| 七段 | 70.1-75.09 | 业务管理者 |
| 八段 | 75.1-85.09 | 高级管理者 |
| 九段 | 85.1-90 | 战略决策者 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 准备数据文件

确保Excel文件包含以下列：
- **基本信息列**：序号、微信昵称、测评时间等
- **能力得分列**：【执行力】【协调力】【优化力】【统筹力】【预见力】【业务力】【财务力】【领导力】【决策力】

### 3. 生成报告

**方法一：直接运行脚本（默认生成PDF）**

```bash
python main.py /path/to/your/data.xlsx -o /path/to/output
```

**方法二：生成文本格式报告**

```bash
# 在代码中指定output_format='txt'
python main.py /path/to/your/data.xlsx -o /path/to/output --format txt
```

**方法三：在代码中调用**

```python
from main import AssessmentReportGenerator

# 创建生成器
generator = AssessmentReportGenerator()

# 生成PDF报告（默认）
output_file = generator.generate_report(
    excel_file='测评数据.xlsx',
    output_dir='./reports',
    output_format='pdf'  # 可选：'pdf' 或 'txt'
)

print(f"报告已生成: {output_file}")
```

## 📊 输出报告内容

### PDF报告包含三大部分：

#### 第一部分：核心发现与总览
- 当前段位等级

每项能力包含：
- 得分和等级
- 详细能力解读

#### 第三部分：个性化发展行动计划
- 优势升华区：针对A级和B级能力

### 报告特色
- 📊 **可视化雷达图**：一目了然地看到能力结构
- 🎨 **专业排版**：清晰的层级结构和色彩系统
- 📱 **PDF格式**：便于分享和打印
- 📝 **详细分析**：每个能力都有深度解读
- 💡 **行动建议**：提供个性化的发展建议

## 🛠️ 技术实现

### 核心逻辑

1. **数据读取**：使用pandas读取Excel文件
2. **分数计算**：提取9大能力维度得分
3. **等级判定**：根据分数区间判定A-E等级
4. **段位匹配**：根据总分匹配九段位
5. **语料库匹配**：从语料库文件中提取对应文案
6. **报告生成**：组合生成完整报告文本

### 评分标准

```python
# 核心基石（8分制）
A级: 7.2-8.0分    B级: 6.4-7.1分    C级: 5.6-6.3分
D级: 4.8-5.5分    E级: 0-4.7分

# 价值引擎（10分制）
A级: 9.0-10.0分   B级: 8.0-8.9分    C级: 7.0-7.9分
D级: 6.0-6.9分    E级: 0-5.9分

# 领导潜能（12分制）
A级: 10.8-12.0分  B级: 9.6-10.7分   C级: 8.4-9.5分
D级: 7.2-8.3分    E级: 0-7.1分
```

## ❓ 常见问题

**Q: 报告生成的格式是什么？**
A: 当前版本生成文本格式（.txt）报告，便于阅读和编辑。后续可扩展为PDF格式。

**Q: 支持批量处理吗？**
A: 当前版本处理Excel文件的第一行数据。如需批量处理，可在Excel中添加多行数据，然后循环调用生成器。

**Q: 语料库文件必须放在哪里？**
A: 语料库文件应放在skill目录的父目录中，与skill目录同级。

**Q: 如何修改报告模板？**
A: 编辑 `main.py` 中的 `_generate_report_content` 方法，自定义报告结构和内容。
