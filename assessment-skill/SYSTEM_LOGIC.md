## 📚 语料库详细映射关系

### 综合段位语料库
```
文件：综合段位语料库.txt

格式：
您的当前段位：[段位名称]
段位释义：[该段位的详细描述，可能多行]

解析后的数据结构：
corpus['rank'] = {
  '一段': '段位释义：您刚踏入...',
  '二段': '段位释义：您已具备...',
  ...
  '九段': '段位释义：您是...'
}

使用场景：
PDF第一部分 → 显示当前用户的段位详细描述
```

### 能力维度语料库
```
文件：能力维度、等级及分数解读语料库.txt

格式：
[能力名称]/A 卓越（分数范围）[A等级描述]
B 优良（分数范围） [B等级描述]
C 合格（分数范围） [C等级描述]
D 需提升（分数范围）[D等级描述]
E 急需改善（分数范围）[E等级描述]

解析后的数据结构：
corpus['ability'] = {
  '执行力': {
    'A': {'score_range': '', 'description': 'A等级描述...'},
    'B': {'score_range': '', 'description': 'B等级描述...'},
    'C': {'score_range': '', 'description': 'C等级描述...'},
    'D': {'score_range': '', 'description': 'D等级描述...'},
    'E': {'score_range': '', 'description': 'E等级描述...'}
  },
  '协调力': { ... },
  ...
  '决策力': { ... }
}

使用场景：
PDF第二部分 → 显示每个能力在对应等级下的详细解读
```

### 个性化发展行动计划语料库
```
文件：个性化发展行动计划语料库].txt

格式：
[能力名称]
1-3段：[针对低段位的建议]
4-6段：[针对中段位的建议]
7-9段：[针对高段位的建议]
7-9段+：[针对超高段位的建议]

解析后的数据结构：
corpus['action'] = {
  '执行力': {
    '1-3段': ['将你高效的日常事务...'],
    '4-6段': ['主动为新同事...'],
    '7-9段': ['主导设计一项跨部门...']
  },
  '协调力': { ... },
  ...
}

段位匹配逻辑：
rank_numbers = {
  '一段': 1, '二段': 2, '三段': 3,  # 低段位 → 优先使用 '1-3段'
  '四段': 4, '五段': 5, '六段': 6,  # 中段位 → 优先使用 '4-6段'
  '七段': 7, '八段': 8, '九段': 9   # 高段位 → 优先使用 '7-9段+'
}

if rank_num <= 3:
  优先使用 '1-3段' 建议
elif rank_num <= 6:
  优先使用 '4-6段' 建议（如果没有则用'1-3段'）
else:
  优先使用 '7-9段+' 或 '7-9段' 建议

使用场景：
PDF第三部分 → 根据用户段位智能匹配对应的行动建议
```

## 💡 关键设计特点

### 1. 百分之百使用语料库
✅ 所有描述性文字均来自txt文件
✅ 无硬编码的评价内容
✅ 易于维护和更新

### 2. 智能匹配机制
✅ 段位自动计算（9个区间）
✅ 等级自动判定（A/B/C/D/E，5个等级）
✅ 建议智能匹配（根据段位选择最合适的建议）

### 3. 批量处理能力
✅ 一次处理Excel所有行
✅ 每行生成独立PDF
✅ 支持大规模数据处理

### 4. 专业PDF输出
✅ 中文字体支持（无乱码）
✅ 雷达图可视化
✅ 清晰的章节划分
✅ 美观的表格布局

### 数据流转关系

```
main.py
  ├─ 【用户输入】
  │   └─ 读取：Excel测评数据.xlsx
  │
  ├─ 【系统内部】
  │   ├─ 初始化时自动加载：综合段位语料库.txt
  │   ├─ 初始化时自动加载：能力维度语料库.txt
  │   ├─ 初始化时自动加载：行动计划语料库.txt
  │   └─ 解析为内存中的数据结构（corpus）
  │
  ├─ 【处理逻辑】
  │   ├─ 提取Excel数据
  │   ├─ 计算段位和等级
  │   ├─ 从corpus中匹配内容（100%来自txt文件）
  │   └─ 调用PDF生成器
  │
  └─ 【生成输出】
      └─ 生成PDF报告文件

pdf_generator_v2.py
  ├─ 接收：用户数据 + 已解析的语料库数据
  ├─ 使用：reportlab（PDF生成）
  ├─ 使用：matplotlib（雷达图）
  └─ 输出：PDF文件流
```

## 🎯 关键理解

### ✅ 用户视角
```
用户只需要做：
1. 准备Excel测评数据文件
2. 运行系统（或上传Excel）
3. 获得生成的PDF报告

不需要关心：
- txt语料库文件（系统内置）
- 如何匹配内容
- 如何生成PDF
```

### ✅ 系统视角
```
系统内部包含：
1. 代码逻辑（main.py, pdf_generator_v2.py）
2. 语料库配置（3个txt文件）
3. 自动处理流程

系统自动完成：
- 加载和解析语料库
- 计算段位和等级
- 匹配对应内容
- 生成专业PDF
```

---

**系统核心特点**：
- 用户端：只需提供Excel文件
- 系统端：内置语料库，自动匹配
- 输出端：生成个性化PDF报告
- 内容源：100%来自txt语料库文件
